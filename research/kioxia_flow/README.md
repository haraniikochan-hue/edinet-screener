# キオクシア(285A) 短期需給・ホルダー行動モデル

短期トレード（1〜5営業日）向けに、信用買い方・株主全体の「苦しさ」を数値化し、
そこから生じる行動（追証→強制決済、投げ、ナンピン、戻り売り）を予測・検証するための作業場。

## 毎日の更新手順
1. `data/` のCSVに前営業日の行を追記する
   - `prices.csv` … 株価4本値・出来高（株探 時系列: https://s.kabutan.jp/stocks/285A/historical_prices/daily/ ）
   - `margin_daily.csv` … 東証の日々公表の信用残（株数・金額）（株探 日次信用残: https://s.kabutan.jp/stocks/285A/historical_margins/daily/ ）
   - `jsf_daily.csv` … 日証金の貸借取引（https://www.taisyaku.jp/app/stock/detail/285A-01 ）。サイトの表示日付は取引日の翌営業日なので、取引日に直して記入する
   - `holders.csv` … 大量保有・変更報告（東芝ほか、EDINET）、0.5%以上の空売り報告（kabu365 / karauri.net）
   - `events.csv` … 直近のイベント
2. 実行（リポジトリのルートで）
   ```bash
   python3 research/kioxia_flow/flow_model.py --now <気配やPTSなどの参考値> --log
   python3 research/kioxia_flow/flow_model.py --backtest 8   # 1日先予測の検証（約30秒）
   ```
3. `reports/<基準日>.md` が生成される。`--log` を付けると、まだ公表されていない日の信用残の予測を `data/predictions_log.csv` に記録する。次回の実行時に実績値が入っていれば、自動で誤差を検証する。

依存はnumpyとpandasのみ。

## モデル構成（レポートの各節）
| 節 | 内容 |
|---|---|
| A | 日次σ・Parkinson σ、窓（夜間）と日中の分解、出来高と値幅の関係 |
| B | 株主全体の取得コスト分布（出来高の一部が毎日入れ替わるとみなす減衰モデル）、Grinblatt–Han型のCGO（含み損益の重心）、価格帯別出来高 |
| C | 信用買い残の日次分解（決済率／新規買い）。決済はどの建玉からも同じ割合で起きると仮定 |
| D | **構造モデル**：建てた日（建値）× 保証金率クラス（30%／50%／100%）ごとに建玉を追跡。日々、追証の判定 →（入金して解消 or 2営業日後に強制決済）、下落率に応じた投げ、上昇率に応じた手仕舞い、下落時のナンピンを計算する。**買い方の資金余力**も状態として持ち、余力が減るほどナンピンと追証解消が減る。9パラメータを東証の日々公表の信用残（株数・平均建値）に合わせて推定（ランダム探索から局所探索、上位100組をアンサンブルに使う） |
| E | まだ公表されていない日の信用残の予測（最終実績値に合わせて補正）、翌営業日の終値シナリオ別の強制決済スケジュール、余力ゼロのストレス、5営業日の経路シナリオ、`--backtest` によるウォークフォワード検証 |
| F | 追証の連鎖：強制決済の平方根インパクト（ΔP/P = Y·σ·√(Q/ADV), Y=0.7）だけで価格を内生的に決めた場合の着地 |
| G | 戻り売りの段階表：建値±3%に戻ると、信用は35%、現物は10%が手仕舞うと仮定した価格帯別の売り供給 |
| H | 大口フロー：東芝の出来高に占める売りの割合、JPMの空売り、TOPIX浮動株比率の第2段階 |
| I | セリングクライマックスの判定（出来高、終値の位置、下ヒゲ、翌日の安値維持、信用残の純減） |
| J | 1・3・5営業日の到達確率（20日リターンの重複ありリサンプリング、平均の傾きは除去） |
| K | 日証金の差引残・逆日歩 |

## 主な仮定（`flow_model.py` の `P` で変更可）
浮動株 約11.9億株（発行済から自己株、東芝、SKハイニックス14%を除く）、追証ライン20%、強制決済は2営業日後、
保証金率クラスは30%／50%／100%、平方根インパクトの係数Y=0.7、戻り売り確率は信用35%・現物10%、TOPIX連動パッシブの保有比率は15〜25%。
いずれも推計。東芝の日別売却株数はXの投稿によるもので未検証（ただし変更報告の1.34ポイント減と整合する）。

## 2026-11-05時点の短期の見立て（参考値 8,100円。ハイパーリキッドのデリバティブ価格）
1. **追証による強制決済は出来高に比べて小さい**。3営業日で約310万株（ADVの約4%）。余力ゼロのストレスでも約340万株。連鎖による追加下落は-1〜2%程度にとどまる。信用買いの約86%は保証金を厚く積んだ層と推定される。
2. **短期の需給を決めるのは、ナンピンが続くか止まるか**。推定余力は、11/5の終値を反映した後で約30%残り。11/6が8,100円で引けた場合の新規信用買いは約320万株。余力がゼロなら約90万株に減り、下支えが消える。
3. **戻ると信用買いの手仕舞いが強い**（上昇率×0.53）。9,300円の窓埋めまでの5日で、投げと戻り売りの合計が約650万株。10,000円なら約840万株。これに東芝の売りが1日あたり約630万株（推計）重なる。
4. **検証できる予測：11/5分の信用買い残は54.56M株 [52.98–55.94M]（前日比+3.3%）**
   - 下限を下回った場合：ナンピンが止まり投げに転じた → 底入れに近づくサイン
   - 上限を上回った場合：まだ買い下がりが続いている → 上値が重い
5. 8,100円からの到達確率（5営業日）：9,300円に届く 27%、10,000円 12%、7,500円まで下がる 47%、7,000円 24%。
6. 1日先予測の検証（直近8日）：誤差（MAE）1.3%。前日横ばいと置く単純な予測は2.2%。

## 短期で入る条件（すべて満たすのが理想）
- 信用買い残がモデル予測の下限を下回る、または2〜3日続けて純減する。日証金の差引残が442万株を割る
- 出来高がADVの1.5倍以上で、終値が高値と安値の間の下から60%以上の位置にあり、翌日にその日の安値を割らない
- 東芝の次の変更報告（約1,640万株の追加売却で提出）が出ない、または出来高に占める東芝の売りの割合が下がる
- 窓のリスクが和らぐ（マイクロン・サンディスクの下げ止まり、S&P 500の7,500回復）

*モデル推計であり、投資助言ではない。*
