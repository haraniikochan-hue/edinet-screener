# キオクシア(285A) 短期需給・ホルダー行動モデル v2

短期トレード（1〜5営業日）向けに、信用買い方と株主全体の「苦しさ」を数値化し、
そこから生じる行動（追証→入金／一部売却／強制決済、投げ、ナンピン、戻り売り）と、
それが価格に与える影響を、Kioxia 自身の全履歴（2024/12 上場〜）に基づいて予測・検証する。

## 毎日の更新手順
1. `data/` の CSV に前営業日の行を追記する
   - `prices.csv` … 4本値・出来高（株探: https://s.kabutan.jp/stocks/285A/historical_prices/daily/ ）。`source` 列は `kabutan`
   - `margin_daily.csv` … 東証の日々公表の信用残（株数・金額）（株探: https://s.kabutan.jp/stocks/285A/historical_margins/daily/ ）
   - `margin_weekly.csv` … 週次信用残（金曜）。2026-09-29 より前の株数は分割調整で×3 済み
   - `jsf_daily.csv` … 日証金（https://www.taisyaku.jp/app/stock/detail/285A-01 ）。サイトの日付は翌営業日表示なので取引日に直す
   - `peers.csv` … MU / SNDK / SOX / SK hynix / N225 の始値・終値。`python3 -c "import yfinance"` が使える環境なら
     `scripts` 相当の取得は `yfinance.download([...], auto_adjust=True)` で再生成できる（米国の当日行は場中だと暫定値）
   - `holders.csv` … 東芝の変更報告（EDINET）、0.5%以上の空売り報告（kabu365 / karauri.net）
   - `events.csv` … 直近イベント
2. 実行（リポジトリのルートで）
   ```bash
   python3 research/kioxia_flow/run.py --now <気配・PTS・海外デリバの参考値> --log      # 約20秒
   python3 research/kioxia_flow/run.py --now <参考値> --backtest 8                   # ウォークフォワード検証つき（約1分）
   python3 research/kioxia_flow/run.py --quick                                        # 探索を軽くして確認
   ```
   - `--now` を省くと、前夜の米半導体株（SOX, MU）から窓モデルで寄付を予測して使う
   - `--gap-sd-scale`（既定0.5）は参考値の信頼度。0=その値で寄る前提、1=参考値を平均とするが窓の不確実性は丸ごと残す
   - `--log` で、未公表日の信用買い残と 1〜5 営業日の終値の予測を `data/predictions_log.csv` に記録。次回実行時に実績が入れば自動で照合する
3. `reports/<基準日>.md` が生成される

依存: numpy, pandas（取得だけ yfinance）。

## 構成（`kxflow/`）
| モジュール | 内容 |
|---|---|
| `config.py` | 制度・仮定パラメータ `P`、営業日、値幅制限表 |
| `data.py` | 読み込み、張り付き判定、米国（前夜）・韓国（同日）ピアの整列 |
| `vol.py` | EWMA 条件付きボラ（λ は擬似尤度で推定、窓と日中は別）、**条件付きブートストラップ**（前日リターン分位→窓、窓分位→日中）、窓の米株モデル、ピアβ残差、イベントスタディ（−10%日・2日−20%・張り付き・窓開け）、局所底の検出、週次信用残の弾力性 |
| `holders.py` | Grinblatt–Han 型の回転率減衰で株主全体の取得コスト分布と CGO、苦痛指数（全履歴 z 化）、**kNN 底値類似度**、戻り売りラダー |
| `structural.py` | **信用買い方の構造モデル**：建値ビンテージ×保証金率クラス（30/50/100%）。毎日、(A) 寄付でキューの売りを執行（張り付き日は 25% のみ）、(B) 自主決済 `b0 + b1·下落率·(1+κ·(含み損−平均))` と建値回復時の『やれやれ売り』倍率、ナンピン `出来高·(n0 + n1·下落率·余力比)`、(C) 大引けで維持率判定 → 入金（余力に依存）／一部売却（翌日寄付）／強制決済（3営業日後の寄付）、(D) 余力の更新 |
| `calib.py` | クロスエントロピー探索 → 擬似尤度の重み付きアンサンブル（有効サンプル数 ≈ 1/3）、識別性（パラメータ相関）、ウォークフォワード |
| `flows.py` | 東芝の売却参加率と次回報告のタイミング、寄付インバランス、TOPIX パッシブ需要 |
| `mc.py` | **統合モンテカルロ**：外生ショック（条件付きブートストラップ×EWMA）＋機械的フロー（強制・一部売却）と東芝売りの平常水準からの超過分に平方根インパクト（Y〜U(0.3,0.9)）＋値幅制限と張り付き（執行率低下・翌日へ持ち越し）。到達確率、エントリー時期別の期待値、戦術表（張り付き時の約定可否を反映） |
| `report.py` | Markdown レポート |

## レポートの読み方（短期）
- **§1 翌営業日**: 寄付・大引けの分布、張り付き確率、寄付の予定売りと典型出来高の比（インバランス）、終値ごとの新規追証、追証の時間割
- **§2 1〜5日**: 到達確率、日次の経路とフロー、**エントリー時期別の期待値曲線**、戦術別の RR、東芝・インパクト・ブートストラップ方式の感応度
- **§3 ホルダー**: 参照価格と含み損、苦痛指数の分位、過去の底との類似度、週次の逆張り弾力性（直近 vs 過去）、建値分布、戻り売りラダー
- **§4 構造モデル**: 推定パラメータ・識別性・日次フロー分解・**未公表日の信用残の予測（翌日に答え合わせ）**・ウォークフォワード
- **§5 実績参照**: Kioxia の過去の −10% 日・2日 −20%・張り付き後の分布、条件付きテーブル、ピアβと固有リターン
- **§6 大口**: 東芝の報告タイミング、空売り報告、TOPIX 第2段階（11/27）
- **§7 判断とチェックリスト**

## 主な仮定（`config.P`）
追証ライン 20%（解消後 25%）、強制決済は追証発生の 3 営業日後の寄付、一部売却は翌営業日の寄付、張り付き日の売り執行率 25%、
初期建玉の建値分散（平均比 0.79/0.94/1.29）、浮動株 ≈ 発行済 − 自己株 − 東芝 − SK hynix 14%、現物の入れ替わり率 α=0.5、
平方根インパクト係数 Y〜U(0.3,0.9)、機械的フローの平常水準＝推定期間の中央値、東芝の平常売り 1.2M 株/日（10/2〜27 の平均、価格変動に織り込み済みとみなす）、
東芝『平常』＝確率 0.5 で出来高の 0.5〜6%、『集中』＝毎日 6〜15%、TOPIX 連動パッシブ 15〜25%。
東芝の日別売却株数は X の投稿（未検証、変更報告の 1.34pt 減と整合）。

## v1 からの主な変更（2026-11-05）
- データ：31 日 → 全履歴 456 日＋米韓ピア＋週次信用残 98 週
- リターン：iid ブートストラップ → EWMA 条件付きボラ、窓／日中分離、前日→窓→日中の条件付きブートストラップ、値幅制限と張り付きの持ち越し
- 構造モデル：追証の解消を入金／一部売却／強制の 3 経路に、投げの含み損集中度 κ と建値回復時の売り倍率を追加、余力の消費を明示、張り付き日の執行制約
- 推定：擬似尤度の重み付きアンサンブル、識別性診断、ウォークフォワード（MAE 0.9% vs 横ばい 2.2%）、予測区間の過信をモデル誤差で補正
- 価格の内生化：統合 MC（フローのインパクトを価格に戻す）、エントリー時期別の期待値、約定可否つき戦術表、東芝レジーム感応度
- 新しい分析：Kioxia 自身のイベントスタディ（底は安値引け→翌日窓上げが典型、2日−20% 後の 3 日は中央値 +19%）、kNN 底値類似度、週次の逆張り弾力性（直近 8 週は過去の 3 倍）、ピアβで説明できない固有リターン（10 日で −32%）、東芝の次回報告タイミング

*モデル推計であり、投資助言ではない。*
