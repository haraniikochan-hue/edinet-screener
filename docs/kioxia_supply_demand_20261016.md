## 0. 結論

1. **需給の主役は東芝**。ベインは 2026年6月までに全株を売却済みです。SK hynix が実質的に支配する SPC2（約14.1%）は売っていません。自社株買い（8,000億円）は 8/10 に完了しています。いま市場で**継続的に売っていると一次資料で確認できる大口は東芝だけ**です。
2. **東芝は 10/1 まで市場内で売り続けていたことが確定しています**（変更報告書 No.21）。売り方は 2025年秋と 2026年で変わりました。
   - 2025年秋: 担保解除分を毎営業日、出来高の 10〜20% のペースで機械的に売却。
   - 2026年6月以降: 寄付が高い日・高値を取りに行く日・ストップ高の日に集中して売却。上に置いた指値が約定する形と整合します。
3. **「分割前1万株・分割後3万株の売り板」説の評価**
   - 東芝の指値売りが板に出ていること自体の蓋然性は高い（7〜8割）。
   - その規則的な1万株/3万株の板が東芝のものかは、可能性が高いが未証明（5〜6割）です。
   - 2026年の日別売却数量は 1万株・1千株ちょうどの日が偶然では説明できない頻度で現れます（p≈10⁻⁹）。分割での×3（1枚あたり約5.4億円で不変）とも整合します。
   - ただし板は匿名で、日次合計の35日中27日は1万株の倍数ではありません。決定打はありません。
4. **今も売っているか**: 開示上は不明ですが、継続している可能性が高いと見ます。止める材料がないためです（担保は解消済み、保有目的は不変、7/30 に現在値と同じ1.2万〜1.5万円の価格帯でも売却、決算日も売却）。
   - ただし売り方が上昇日に偏っているため、10/2〜10/16 の急落局面で実際に売れた量は推計で約680万株（期間出来高の約1.5%）にとどまります。**今回の急落の主因ではありません**。
   - 次の変更報告書が出るには、あと約1,650万株の売却が必要です。従来ペースなら 10月末〜11月中旬に報告義務が発生する計算です。
5. **需給インパクト**: 東芝の残り1.94億株（約2.6兆円）は、平均ペースで消化すると約8〜10か月（2027年夏頃まで）かかります。下げを主導する売りではありませんが、**戻りを売る「上値の蓋」**として効きます。
   - さらに SPC2（約3.1兆円）と、報道ベースの ADR 調達（100億ドル以上、2027年4〜6月）が潜在供給として控えます。
   - 信用買い残（10/9 時点 4,480万株、倍率29.8倍）の整理も途中です。
6. **期間別のエントリー合理性**

   | 期間 | 合理性 | 理由 |
   |---|---|---|
   | 短期 | 低〜中 | 売られすぎではあるが、信用整理と東芝の戻り売りで戻りは鈍くなりやすい |
   | 中期 | 中 | 業績モメンタムと PER 4倍台は魅力。ただし供給イベントが多いので分割エントリー前提 |
   | 長期 | 中〜低 | ピーク業績での PER は当てにならない。下落した分、ある程度織り込み済みではある |

## 4. 「分割前1万株・分割後3万株の売り板」仮説の検証

### 4.1 何が検証でき、何ができないか

- 東証の板は匿名です。注文主は分かりません。
- 変更報告書には、**日別の売却合計**（「最近60日間の取得又は処分の状況」）しか載っていません。
- よって「板に出ている1万株/3万株が東芝のものか」は直接は証明できません。状況証拠の積み上げで蓋然性を評価します。

### 4.2 支持する証拠

1. **2026年は日別売却数量に「丸い数字」が異常に多い**（分割前株数で検定）。
   - 1万株ちょうどの倍数: **35日中8日**（1万株、100株単位の数量が偶然そうなる確率は1%、二項検定 p≈2×10⁻⁹）
   - 1千株ちょうどの倍数: **35日中15日**（偶然なら10%、p≈5×10⁻⁷）
   - 例: 5,940,000 / 1,200,000 / 890,000 / 860,000 / 420,000 / 370,000 / 300,000 / 100,000 株
   - 対照的に 2025年の C1（アルゴ執行）では、1千株の倍数は17日中2日で偶然と区別できません。
   - → **2026年は、決まったサイズの注文を出してそれが全量約定する、という執行に変わった**と読めます。
2. **価格条件付きの売り**（3.3節）。上に置いた指値は板に見えます。
3. **分割でちょうど3倍**。1万株×約5.4万円＝約5.4億円、3万株×約1.8万円＝約5.4億円で、**1枚あたりの金額は不変**です。ブローカーがコーポレートアクションに合わせて発注数量を調整した、と考えると自然です。個人の見せ板やマーケットメイクのアルゴが、ちょうど3倍に揃える理由は乏しいです。
4. **他に該当する大口売り手が見当たらない**。
   - ベインは撤退済みです。
   - SPC2 は動いていません（1%未満の売買なら報告義務はないため、完全には否定できません）。
   - 0.5%以上の空売りポジションは 9/30 以降ありません。
   - 東芝は一次資料で確認できる唯一の継続的な売り手です。

### 4.3 反する証拠・限界

1. **日次合計の35日中27日は1万株の倍数ではありません**。1万株の注文の最後の1枚が一部だけ約定して引けた、と解釈することはできますが、子注文のサイズが常に1万株だったとは言えません。
2. **7/31（ストップ高・比例配分）の売却量は 645,000株（分割前）**で、1万株の倍数ではありません。
   - 張り付きの日は、上限値以下の売り注文が全量約定します。
   - したがって、その日の東芝の売り注文の合計が 645,000株だったことになります。
   - 1万株ちょうどの注文を並べるだけの運用だったとは言い切れません。
3. 板の匿名性、丸い数量はほかの参加者も使うこと、観察者の確証バイアス（目立つ板だけ覚えている）。
4. インパクトを抑えたい大口は、通常は大きな固定サイズを見せません。約5億円の板を見せ続けるのはやや異例です。ただし、上値を抑える意図などがあれば説明はつきます。

### 4.4 蓋然性の評価

| 命題 | 評価 |
|---|---|
| 東芝が市場で継続的に売っている（10/1 まで） | **確定**（一次資料） |

## 5. 今も売られているのか

**確定している範囲**

- 9/29 に 468,600株、10/1 に 3,924,200株を売却しています。
- いずれも**分割後の株数**です。保有株数の整合性からも確認しました（分割前 66,195,300株 × 3 − 468,600 − 3,924,200 = 194,193,100株）。
- つまり「3万株の時代」に入ってからも売っています。

**継続していると考える理由**

- 担保の制約がありません。
- 保有目的の記載は不変ですが、行動は一貫して処分です。
- 7/30（分割調整後の安値12,007円〜高値15,013円）にも 235.9万株を売っています。現在値とほぼ同じ価格帯で売った実績があり、現在値より上に高い下限価格を設けている証拠はありません。
- 決算日（7/30・7/31）にも売っており、決算前に売買を止める様子はありません。

**10/2〜10/16 の推計**

- C4 の「寄付ギャップ別の平均売却量」を当てはめると、合計 約680万株（期間出来高の約1.5%）です。
- 同期間の下落（約−32%）は、次の要因で十分説明できます。東芝は主因ではありません。
  - 同業比（10/2→10/15〜16）: SanDisk −19%、SK hynix −29%、Samsung −21%、Micron −13%、SOX −12%
  - 中国 CXMT の 4F² DRAM 発表（10/12）、米 CPI 上振れ、AI 設備投資への懸念
  - 信用買いの投げ
- キオクシアの下げが SanDisk より約13ポイント大きいのは、信用買い残の大きさや東芝・ADR などの供給懸念といった、銘柄固有の需給の差と考えられます。

**次の変更報告書（No.22）の目安**

- 報告義務は、保有割合が 11.80% から 1ポイント以上減ったとき（保有 1.777億株以下）に発生します。そのためにはあと約1,651万株の売却が必要です。
  - C4 平均ペース（92万株/日）なら 10/1 から約18営業日後（10/27〜28頃）に義務が発生し、5営業日以内、つまり 11/4 頃までに提出されます。
  - 下落局面でペースが落ちていれば、11月中旬以降になります。
- **11月末までに報告が出なければ、売却を大きく減速・停止した**可能性が高いと判断できます。
- 別の可能性として、ブロック取引（ABB）や、2027年の ADR での売出し参加で一括処分することも考えられます。その場合は日々の上値の重しが消える代わりに、一時的なディスカウントと需給悪化を伴います。

## 9. 期間別のエントリー合理性

### 短期（〜1か月、10/30 決算と信用残の整理まで）: **合理性 低〜中**

**有利な点**

- RSI 約30、25日線から −25%、2週間で −32% という売られすぎ。
- 10/15 には出来高を伴う投げ（7,900万株）が出た。
- 4Q の NAND 価格見通しは強く、10/30 に強い 10〜12月期ガイダンスや追加の自社株買いが出れば反発の起点になり得る。

**不利な点**

- 信用買い残 4,480万株のしこりがある。
- 東芝の指値売りが戻りを売る（ギャップアップの日ほど売る、という実証結果）。
- セクターのモメンタムが悪化している（SOX、CXMT）。
- 年率80%超のボラティリティで、決算でのギャップも大きい（7月は失望、翌日ストップ高）。

**合理的にやるなら**

- 10/20 の信用残で買い残の明確な減少を確認する。
- 10/15 安値（12,675円）を割り込まないことを確認する。
- そのうえで少額で入り、戻りの目標は控えめにする（窓埋めの 15,000〜16,000円帯）。東芝の売りがある以上、V字回復を前提にしない。

### 中期（1〜6か月）: **合理性 中**

**有利な点**

- 業績モメンタムは少なくとも 10〜12月期まで上向き。
- 年換算 PER 4倍台で、高値から −65% と、ピークアウト懸念はかなり織り込まれている。
- 追加の自社株買いの余力がある。
- ADR 上場後の米国指数採用という需要の種もある。

**不利な点**

- 潜在供給が約7兆円ある（東芝 → 2027年夏頃まで、SPC2、ADR）。
- 12〜1月に制度信用の期日がある。
- 「業績は過去最高、株価は下落」というメモリ株の典型的な局面である可能性。

**合理的にやるなら**

- 3〜4回に分けて時間分散する。
- 確認点ごとに買い増すか止めるかを判断する。
  - 10/30 決算
  - TrendForce の 1Q27 価格見通し（12月末頃）
  - 東芝の変更報告書のペース
- 供給イベント（東芝のブロック、ADR の価格決定）でディスカウントが出たら、そこで拾う方が期待値は高い。

### 長期（1〜3年）: **合理性 中〜低**

- 現在の利益水準（年換算 約5兆円）は、2026年3月期の純利益 5,544億円の約9倍で、典型的なサイクルのピーク圏です。
- 平常時の利益を1〜2兆円と置けば、平常化した PER は11〜22倍になり、割安とは言いにくい。
- 長期の妙味は、AI 推論やデータセンター向け大容量 SSD の需要がどこまで価格を下支えするか、各社が投資規律を保てるかに依存します。
- 歴史的に、メモリ株の良い長期エントリーは「赤字・高 PER・減産」の局面です。
- **長期で持つ前提なら**、現水準では少額の時間分散にとどめるのが合理的です。本格的な積み増しは、次の NAND 価格下落局面か、東芝・SPC2・ADR の供給が片付いた後の方が筋が良いと考えます。
