## 1. プロジェクト概要

EDINET開示企業（日本上場 約3,848社）の財務データを6軸30点でスコアリングし、
Streamlit WebアプリでスクリーニングできるツールA。

**特徴**: スコアの配点は「良い企業の条件」ではなく、**実際の株価リターンとの相関分析**に基づいて設計。
ROE水準やEPS成長年数のような従来型指標（相関ほぼゼロ）は除外し、
配当安定性・ROEの安定性・時価総額など実際にリターンと相関が高い指標で評価する。

## 4. 現行スコアリングモデル（evidence_scorer.py）

### 設計根拠

3,848社の財務指標と株価リターンのSpearman順位相関を実測。
p < 0.001 かつ複数リターン変数で一貫して有意な指標のみ採用し、
相関の強さに比例して配点。

### 6軸・30点の内訳

| 軸 | 配点 | サブ項目 | 根拠相関（1年） | 根拠相関（5年） |
|----|------|----------|----------------|----------------|
| **A. 利益の安定性** | 8 | ROEσ(4) + 赤字年(2) + 営業利益率CV(2) | -0.26 / -0.20 / -0.07 | -0.37 / -0.31 |
| **B. 株主還元力** | 8 | 配当連続年数(4) + 増配年数(4) | +0.28 / +0.28 | +0.43 / +0.49 |
| **C. 割安度** | 5 | PBR業種相対(2) + PER業種相対(2) + 配当利回り(1) | -0.06 / +0.02 / -0.11 | — |
| **D. キャッシュ創出力** | 4 | FCF利回り(2) + FCF黒字年数(1) + アクルーアル(1) | +0.15 / +0.06 | — |
| **E. 成長の持続性** | 3 | BPS増加年数(2) + 営業利益率水準(1) | +0.17 | +0.34 |
| **F. 市場評価** | 2 | 時価総額(2) | +0.35 | +0.48 |

### ランク判定

| ランク | 必要スコア | 現在の分布 |
|--------|-----------|-----------|
| S | 24点以上 | 4社 |
| A | 19〜23点 | 311社 |
| B | 14〜18点 | 1,552社 |
| C | 9〜13点 | 978社 |
| D | 8点以下 | 1,003社 |

### 各項目の判定基準

**A1: ROE標準偏差 (0-4点)** — 相関 r=-0.29
```
σ < 2%pt → 4点 / σ < 4%pt → 3点 / σ < 6%pt → 2点 / σ < 10%pt → 1点 / else → 0点
```

**A2: 赤字年なし (0-2点)** — 相関 r=-0.20
```
6年間黒字維持 → 2点 / 赤字年あり → 0点
```

**A3: 営業利益率CV (0-2点)** — 相関 r=-0.07
```
CV < 0.15 → 2点 / CV < 0.30 → 1点 / else → 0点
```

**B1: 配当連続年数 (0-4点)** — 相関 r=+0.32
```
全年配当 & N≥6 → 4点 / 全年配当 & N≥4 → 3点 / ≥4年 → 2点 / ≥2年 → 1点 / else → 0点
```

**B2: 増配年数 (0-4点)** — 相関 r=+0.29
```
≥5年 → 4点 / 4年 → 3点 / 3年 → 2点 / 2年 → 1点 / else → 0点
```

**C1: PBR業種相対 (0-2点)** — 相関 r=-0.16
```
業種中央値比 < 0.6 → 2点 / < 0.85 → 1点 / else → 0点
(中央値なし: PBR < 0.8 → 2点 / < 1.2 → 1点)
```

**C2: PER業種相対 (0-2点)**
```
業種中央値比 < 0.7 → 2点 / < 0.9 → 1点 / else → 0点
(中央値なし: PER < 15 → 1点)
```

**C3: 配当利回り (0-1点)**
```
≥ 2.5% → 1点 / else → 0点
```

**D1: FCF利回り (0-2点)** — 相関 r=+0.15
```
FCF/時価総額 > 8% → 2点 / > 4% → 1点 / else → 0点
```

**D2: FCF黒字年数 (0-1点)**
```
≥ 5年 → 1点 / else → 0点
```

**D3: アクルーアル比率 (0-1点)**
```
< -0.03（営業CFが利益超過）→ 1点 / else → 0点
```

**E1: BPS増加年数 (0-2点)** — 相関 r=+0.17
```
≥ 5年 → 2点 / ≥ 3年 → 1点 / else → 0点
```

**E2: 営業利益率水準 (0-1点)**
```
業種中央値の1.3倍以上 → 1点 / else → 0点
(中央値なし: ≥ 12% → 1点)
```

**F1: 時価総額 (0-2点)** — 相関 r=+0.35
```
≥ 1兆円 → 2点 / ≥ 1000億円 → 1点 / else → 0点
```

### 各項目に💡コメント付き

全項目にスコア水準に応じた根拠説明（💡）を付与。
例: 「ROEのブレが極めて小さい（σ=0.8%pt）。利益構造が安定しており、株価リターンと最も強い正の相関を持つファクター」

## 5. 相関分析で判明した重要な発見

### リターンと強い相関がある指標（採用）

| 指標 | 1年相関 | 3年相関 | 5年相関 | 意味 |
|------|---------|---------|---------|------|
| 時価総額 | +0.35 | +0.46 | +0.48 | 大型株が一貫して有利 |
| 配当連続年数 | +0.28 | +0.39 | +0.43 | 安定配当は強力な正のシグナル |
| ROEσ | -0.26 | -0.37 | -0.37 | ROEの安定性が重要（水準ではない） |
| 増配年数 | +0.28 | +0.44 | +0.49 | 長期ほど相関が強化 |
| 赤字有無 | -0.20 | -0.31 | -0.31 | 赤字年がある企業はリターンが劣後 |
| BPS増加年数 | +0.17 | +0.28 | +0.34 | 純資産蓄積は中長期で効く |
| forwardPE | +0.27 | +0.24 | +0.15 | 高forward PE=成長期待→実現 |

### リターンと相関がほぼゼロだった指標（旧バフェットモデルで重視→除外）

| 指標 | 1年相関 | 旧モデルの位置 |
|------|---------|---------------|
| **ROE平均値** | **-0.005** | 経済的堀の主軸（高配点） |
| **EPS増加年数** | **+0.010** | 成長性の主軸 |
| 自己資本比率 | -0.041 | 財務の保守性 |
| EPS CAGR 5年 | +0.003 | 成長性 |

### 注意すべき発見

- **trailingPE（実績PER）**: 1年では無相関(+0.02)、5年では低PERが有利(-0.10)
- **forwardPE（予想PER）**: 全期間で有意な正の相関(+0.27)。現モデルではPERを「低い方が良い」で評価しているが、forward PEは「高い方がリターンが高い」（成長期待シグナル）
- **配当利回り**: 負の相関(-0.11)。高配当利回り = 株価下落の結果が多い

## 13. 主要クラス・関数のAPI

### EvidenceReport（lib/evidence_scorer.py）

```python
@dataclass
class EvidenceReport:
    edinet_code: str           # EDINET企業コード
    company_name: str          # 企業名
    industry: str              # 業種
    ticker: str                # ティッカー（例: 9678.T）
    sections: list[ScoreDetail] # 6軸の詳細スコア
    strengths: list[str]       # 強み（最大5項目）
    concerns: list[str]        # 懸念（最大5項目）

    score_total -> float       # 総合スコア（0-30）
    max_total -> int           # 満点（30）
    rank -> str                # ランク（S/A/B/C/D）
```

### 主要関数

```python
# lib/evidence_scorer.py
score_company(row, industry_medians) -> EvidenceReport  # 1社スコアリング
score_all(profiles) -> list[EvidenceReport]             # 全社スコアリング
reports_to_dataframe(reports) -> pd.DataFrame           # DF変換

# lib/data_loader.py
build_company_profiles() -> pd.DataFrame                # 全CSV統合+統計量計算
get_company_timeseries(edinet_code) -> (fin_df, ratios_df)  # 1社の時系列
```
