## 1. ゴール

自宅の Xiaomi TV（Google TV / Android TV 想定）を、

1. **軽く・広告なしにする**（ADB による不要アプリ無効化・アニメーション短縮・ランチャー差し替え）
2. **自作のホーム画面（ランチャー）を入れる**：ニューヨークの街並み写真のスライドを背景に、天気・株・マーケット情報などのダッシュボードと、アプリ一覧を表示する
3. （任意）同じ画面をスクリーンセーバーとしても使う

root 化はしない。すべて ADB と通常の APK インストールの範囲で行う。

## 2. 前提・環境

| 項目 | 内容 |
|---|---|
| TV | Xiaomi TV（**型番未確認**。日本で販売の A Pro / Max 系なら Google TV。中国版 PatchWall の場合は手順が変わる） |
| 操作 | リモコン（D-pad）のみ。タッチ不可 |
| 解像度 | デザインは 1920×1080 基準（4K TV でも UI は 1080p 相当で描画される） |
| 開発環境 | PC があれば PC 上の Claude Code から `adb` で TV を直接操作するのが最速。スマホのみの場合は下記「開発ループ」参照 |

### 開発ループ（スマホのみの場合）
- クラウド版の Claude Code / Codex は自宅 LAN の TV に直接つながらない。
- コード作成・APK ビルドはクラウド側で行い、**TV への接続とインストールは Android スマホの Termux**（`pkg install android-tools`）から行う。
  - `adb connect <TVのIP>:5555` → `adb install -r app-debug.apk`
- PC がある場合は PC の Claude Code が adb で直接インストール・ログ確認（`adb logcat`）まで回せる。

## 3. 推奨アーキテクチャ

**ネイティブの薄いランチャー（Kotlin）＋ 中身は Web（HTML/CSS/JS）** のハイブリッド。

```
┌──────────── Android アプリ（Kotlin） ────────────┐
│ MainActivity  … HOME / LEANBACK_LAUNCHER intent   │
│   └ 全画面 WebView … dashboard/index.html を表示 │
│ JS Bridge     … installedApps() / launch(pkg)    │
│ DreamService  … 同じ WebView でスクリーンセーバー │
└──────────────────────────────────────────────────┘
            ↑ assets に同梱 or 自分のサーバから配信
┌──────────── dashboard（Web） ────────────────────┐
│ 各ウィジェット = API から取得 → 描画            │
│ 写真スライド（フェード＋ゆっくりズーム）        │
└──────────────────────────────────────────────────┘
```

理由:
- デザイン変更が HTML の書き換えだけで済み、ブラウザで確認できる（TV に入れ直す回数が減る）。
- アプリ一覧・起動などランチャーに必要な部分だけネイティブで書く。
- TradingView の公式ウィジェットもそのまま埋め込める。

実装メモ:
- ランチャー化: `<category android:name="android.intent.category.HOME"/>` と `DEFAULT`、および `LEANBACK_LAUNCHER` を intent-filter に。
- アプリ一覧: `PackageManager.queryIntentActivities(Intent(ACTION_MAIN).addCategory(CATEGORY_LEANBACK_LAUNCHER))`、バナー画像は `ApplicationInfo.loadBanner()`。Android 11+ は `<queries>` 宣言が必要。
- JS Bridge: `@JavascriptInterface` で `getApps()`（JSON）と `launchApp(packageName)` を公開。
- フォーカス操作: Web 側で D-pad（矢印キー）でアプリタイル間を移動できるようにする。フォーカス中のタイルは拡大＋アクセント色の枠。
- スクリーンセーバー: `DreamService` を実装し、`android.service.dreams.DreamService` の intent-filter と `BIND_DREAM_SERVICE` 権限を付与。設定のスクリーンセーバーで選択。
- 非力な TV チップ対策: 写真は 1920px 程度に縮小してキャッシュ、アニメーションは transform / opacity のみ、更新間隔は控えめに。

## 6. 進め方（フェーズ）

1. **TV の軽量化（ADB）** … 下記「ADB メモ」。型番確認と `pm list packages` の結果を見て、止めるアプリを決める。
2. **ダッシュボードの Web 版** … `03-all-in-one.html` をベースに、各ウィジェットを実データにつなぐ。PC/スマホのブラウザで確認。
3. **ランチャー APK** … WebView＋JS Bridge でアプリ一覧と起動を実装。TV にインストールし、ホームに設定。
4. **スクリーンセーバー**（任意）… DreamService で同じ画面を表示。
5. **仕上げ** … 時間帯で表示切替（例: 朝は天気中心、夜は写真＋マーケット）、リモコンで画面を切替、パフォーマンス調整。

## 7. ADB メモ

```sh
# TV 側: 設定 → システム → 端末情報 → 「Android TV OS ビルド」を 7 回押す → 開発者向けオプションで（ネットワーク）ADB デバッグを ON
adb connect <TVのIP>:5555
adb shell pm list packages                     # 一覧（これをもとに仕分け）
adb shell pm disable-user --user 0 <package>   # 無効化
adb shell pm enable <package>                  # 元に戻す

# アニメーション短縮（0.5 or 0）
adb shell settings put global window_animation_scale 0.5
adb shell settings put global transition_animation_scale 0.5
adb shell settings put global animator_duration_scale 0.5

# DNS で広告ブロック（例: AdGuard DNS）
adb shell settings put global private_dns_mode hostname
adb shell settings put global private_dns_specifier dns.adguard-dns.com
```

**止めてはいけないもの**
- 地デジ・チューナー関連（止めると放送が見られなくなる）
- Google Play 開発者サービス、システム UI
- 標準ランチャー（代わりのランチャーを入れて動作確認するまでは止めない）

TV のアップデートで無効化したアプリが復活することがある。

## 12. HIP-3全銘柄・24時間チャート・ガラス調UI（v0.4.0 / 2026-10-19 JST）

**最新のレイアウトは第20節、経済指標の実装は第13節を参照。この節で第10・11節の「残り7銘柄未接続」「配信元未決定」は解消しています。**

### ユーザー確定事項

- 12銘柄の統合一覧。BTC・HYPEの重複なし。SPXではなくSP500、NDXではなくXYZ100など、対応するHIP-3契約を使用。
- ダウの枠は **SOXL**。VIXの枠は **DRAM**。SILVERは使用しない。
- チャートは **24時間固定**。期間切替は不要。
- UIは **Apple TV / 最近のiOSを参考にしたガラス調**。半透明・ぼかし・光の縁・角丸・アプリの浮き上がるフォーカス。読みやすさを維持。
- 朝晩同じフル版、渋谷区、Spotify、スポーツなし、外部写真の希望は継続。

### 実装

- `market-definitions.js`：SP500/BTC/HYPE/JP225/SOXL/XYZ100/JPY/DRAM/GOLD/CL/30Y/10Yを正確な契約IDに対応。xyzの8銘柄、paraの2銘柄、nativeの2銘柄。
- 公開メタデータで実在・非廃止を確認しWebSocketを購読。RESTで部分障害を補い、正常時も5分ごとに上場状態を再確認。廃止した銘柄の残存価格は表示しない。
- 全銘柄は無期限先物の `markPx` と24h比。JPYの逆数変換や指数の倍率調整をしない。10Y/30Yは契約価格をそのまま表示し、FREDの%・bpとは区別。
- `market-chart.js`：実際の15分足から24時間チャートを作成。点線は最初の足の始値。緑/赤の線と薄い面。欠損時間と古い終点を保つ。マーク価格の履歴とは区別。
- 銘柄アイコン10点はHyperliquid公開画像、国債2点は一般的な独自アイコン。出典JSONを同梱。
- マーケットを広げ、銘柄名・チャート・価格を整列。TVは2列、縦画面は1列。ガラス効果非対応時と透明度軽減設定のフォールバック。
- 左側のECB/FRED日次カードを維持し、ウォッチリストへの混入は廃止。CoinGecko選択時もHIP-3のその他10銘柄は維持し、BTC/HYPEに異なるソースの履歴を混ぜない。
- 24件の単体テスト。実APIで12銘柄の価格・履歴・WebSocket、5画面サイズ、D-pad・設定・通信断キャッシュを確認。上場廃止・ソース切替とSpotify/写真/ブリッジは制御レスポンスで検証。

### 残作業

Spotifyの実Client ID・ユーザー認証、Unsplashの実Access Key、TV実機とAPKは未接続。初期背景は出典付きCC0写真1枚。実相場の接続にキーは不要。Sitesの公開ヘルパーがないためホスティングは未公開。次の担当者はREADMEの起動・接続手順と契約対応表を参照。
