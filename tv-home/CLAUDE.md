# CLAUDE.md

このリポジトリは、自宅の Xiaomi TV（Google TV 想定）用の自作ホーム画面（ランチャー）とダッシュボードを作るプロジェクト。

- **v0.10.0からテレビのホーム画面はAndroidアプリ（`android/`）**。標準ホームは無効化済み（HANDOFF第3.4節、戻し方あり）。
- 最初に **`START_HERE.md`・`HANDOFF.md`・`AGENTS.md`** を読む。現行はv0.31.0（自宅のドックに入力切替。ソースのみ、未ビルド・未インストール。以下v0.30.1：ビルド済み・テレビは未インストールでv0.30.0。v0.30.1は入れ替え直後の1回目のボタンも切り替える。リモコンのプライムビデオのボタンでSpotifyを開く：ボタンの行き先はXiaomiのシステムが固定しているので、プライムビデオが前に出た直後にユーザー補助サービスがSpotifyへ切り替える。キーは受け取らない。以下v0.29.0まで：テレビをつけたら時間帯に合う写真とテーマに直り、ライトテーマは写真が透けるガラスと光の縁、選んだアイコンや行は拡大後の大きさで描き直してくっきり。以下v0.28.0まで：ライト・ダークの2テーマを表示中の写真の時間帯で切り替え、写真はニューヨークの日中・夕暮れ・夜景。写真の上の文字は白に統一、ドックとウィジェットは同じガラス。キーを受け取るユーザー補助はこのテレビで音量の長押しを止めるので使わない。音量の変化を見て長押しを加速し、テレビの設定はホームボタン2回押し。MacのDockのような中央のドック、写真の出典は上部。ドックの選択から光の演出をやめ、MacのDockのように。経済指標カードをめくると市況への影響が大きい25社の決算予定。最後の行で↓はページボタン、さらに↓でドック）。（v0.9.0までの内容：v0.5.5の配置を保ったデザイン刷新、TV向け軽量化、広告ブロック、リモコン操作の改善、TV専用化）。ユーザーはApple／iOSのようなデザインを好み、UIをさらに洗練させたいと考えている。
- **TV専用**。ユーザーは「モバイル版は作らなくていい」と明言。シートやトーストも含めて1920×1080の `#screen` 1枚に収め、全体を縮尺する（HANDOFF第3.3節）。スマホ・縦画面の配置は追加しない。
- ユーザーのMac上のセッションで続ける（クラウドからは家のWi-Fi・テレビに届かない）。道具・キー・テレビへの接続とAPKの入れ替え手順は `HANDOFF.md` 第1.1節。テレビを変更する操作は、対象・影響・戻し方を説明して確認を取ってから。ユーザーがテレビを使っていることが多いので、`adb shell input` でキーを送るテストはしない。
- デザインの基準は `dashboard/` と `artifacts/dashboard-desktop.png`。`mockups/` と `docs/HANDOFF_HISTORY.md` は過去の経緯。
- 確定済みの地域・銘柄・朝晩の表示・アプリ・余白を引き継ぐ。SmartTubeは見た目だけYouTubeであり、起動先をYouTubeに変えない。
- 未接続事項と次の作業候補は `HANDOFF.md` に記載。次の依頼に必要な未確認情報だけ質問する。
- `dashboard/`を編集し、`android/` でAPKを作り直してテレビに入れる（`dist/`は静的配信用で、`npm run build`で再生成）。実API・制御レスポンス・実機未検証を区別して記録する。
- API キーはコミットしない。
- コミットしたら、確認せずにすぐ同じブランチ `ccr-123aaf7c-88ru7c` へpushする（2026-10-19のユーザー指示「毎度それ聞かないで勝手にpushして」）。プルリクエストは頼まれるまで作らない。
- TVのシステムアプリを無効化するコマンドは、対象と影響を説明してユーザーの確認を取ってから実行する。引き継ぎ作成はTV変更や公開の許可ではない。
